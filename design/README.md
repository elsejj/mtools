## 核心设计决策概要汇总

| 决策点               | 采纳方案                                                  | 核心技术原因                                                                                                       |
| :------------------- | :-------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------- |
| **窗口形态与行为**   | 普通桌面窗口，记忆上次位置与大小                          | 符合桌面生产力工具习惯，避免悬浮窗误关导致的上下文丢失，保证大篇幅代码/翻译对比的宽阔阅读空间。                    |
| **工具可扩展性**     | 支持完整的自定义工具（增删改配）                          | 支持用户自由扩展代码脚本、AI Prompt 及私有命令行，满足个性化工作流。                                               |
| **工具后置处理**     | 默认无 / 复制到剪贴板 / 按时间命名存文件                  | 满足如“批量OCR自动存文档”、“代码转换后秒贴回IDE”等自动化工作流，且各工具可隔离专属目录。                           |
| **多模态与视觉识别** | 统一采用多模态大模型                                      | 主流大模型已原生整合视觉能力，无需在本地维护臃肿的第三方 OCR 库，接口更精简、鲁棒性更高。                          |
| **外部命令安全性**   | 用户显式指定，用户自行对安全负责                          | 最大化系统灵活性，支持调用系统内已有的 CLI/脚本（如 Python、Shell、jq），免除沙箱过度限制。                        |
| **智能纠偏体验**     | 强特征优先纠偏 + 候选栏快速切换                           | 杜绝由于用户上一轮操作遗留停留在不匹配工具上的卡顿感，达到“一键出结果”。                                           |
| **嗅探与数据架构**   | Rust 原生可插拔管道 (`ContentSniffer` Trait) + 瘦前端呈现 | 通过 Trait 插件注册表统一管理内置与动态正则嗅探器，高内聚低耦合，极速预处理且便于后续无缝扩增新格式。              |
| **前置解码解包机制** | Base64 / Hex / URL-Percent 作为编码，先解码还原再嗅探     | 彻底揭开内嵌的真实数据实体（如 Base64 编码的 JSON 或图片魔数），自动升格为对应类型直达目标工具，并保留解码溯源链。 |
